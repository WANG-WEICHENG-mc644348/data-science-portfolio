# data-science-portfolio

Personal data science portfolio site, published with **GitHub Pages**.

The site is built from [`index.md`](index.md) in the repository root and is
served at:

> https://wang-weicheng-mc644348.github.io/data-science-portfolio/

It presents my background, technical skills, and a featured data science
project on digital media and public trust in China's judiciary.

## Featured project

- **Repository:** [data-science-project](https://github.com/WANG-WEICHENG-mc644348/data-science-project)
- **Question:** Did digital media erode trust in China's courts?
- **Data:** China General Social Survey (CGSS) 2017 & 2023
- **Status:** ongoing

## Local preview

```bash
bundle exec jekyll serve      # if you have Jekyll installed
```

Or simply push changes to `main` — GitHub Pages rebuilds the site
automatically.
